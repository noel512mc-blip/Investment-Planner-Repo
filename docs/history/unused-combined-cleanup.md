# Unused all-person accumulation cleanup

## Changed files

- js/app.js: removed only the dead accumulator declarations, additions and their post-household scenario inflation work.
- js/appCalculation.test.html: updated the two all-person cases to assert used scalar totals and existing public results without controller source injection.
- docs/unused-combined-cleanup.md: this report.

Other production JavaScript, HTML, CSS, the retirement suite and the profit-donut suite remain unchanged, verified against their saved hashes. No feature extraction was started.

## Consumer search evidence

Before editing, rg searched js/ and v0.01.html for every occurrence of the five accumulator names and both separate scenario-result names. All production references to the five accumulators were confined to _calculateInvestmentCore. The other references were the recent test expectations and injected observation hook. No production chart, card, callback, storage function or helper consumed any of these accumulated values.

The += operations read their own running totals solely to write the next total; none had a downstream consumer. Post-cleanup searches for these names and __allPersonSnapshot in production/tests return no matches. Historical reports still describe the old baseline and are retained as records.

## Exact removals

1. Five declarations: three zero-filled year arrays (combinedBalances, combinedBullBalances, combinedBearBalances) and two zero scalar totals (combinedBullFinal, combinedBearFinal).
2. The base-result balances.forEach loop that only added to combinedBalances.
3. The post-household useInflation block that mapped combinedBullResult.balances and combinedBearResult.balances through yearly inflation divisors, calculated the final inflation multiplier, and divided both scenario final balances by it.
4. The two additions to combinedBullFinal/combinedBearFinal.
5. The two scenario balances.forEach loops adding to combinedBullBalances/combinedBearBalances.

The inflation work in item 3 had no remaining consumer after items 4 and 5 were removed. It ran AFTER the household helper had already accumulated the nominal scenario numbers by value, so deleting it cannot change household totals or histories.

## Values deliberately kept

- combinedBullResult and combinedBearResult are still generated by the same simulateInvestment calls (now app.js:4024 and :4034), with the same rates, offsets, contributions and formulas. They are supplied to accumulateHouseholdProjection at :4054 and :4055, preserving nominal household bull/bear values.
- combinedFinal is still accumulated and used by portfolioSummaryData.total (:4446) and the combined Total Value card (:4893).
- combinedInvested and combinedProfit are still accumulated and displayed by their summary cards (:4901 and :4909).
- combinedInvestedBalances is not one of the dead arrays. It retains its household-only accumulation and serves break-even analysis (:4461) and the invested-capital chart (:5030).
- Individual timeline arrays, per-person projections, selected-household base/profit/scenarios, chart datasets, HTML, UI state, storage and CSS are unchanged.
